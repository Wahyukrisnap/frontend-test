# Frontend Skill Test

## Project

Digital Agency Landing Page.

## Technology

- HTML5
- CSS3
- JavaScript

## Features

- Responsive landing page
- Mobile navigation
- Anchor navigation
- Branding, Design, and Marketing tabs
- Project slider with pagination and previous/next controls
- Analytics `dataLayer` tracking

## Browser Target

- Mozilla Firefox
- Internet Explorer compatibility consideration

## Analytics

Anchor points are prepared for Google Tag Manager / Google Analytics tracking.
Clicks push an `anchor_point_click` event to `window.dataLayer` with the
`link_name` and `destination` values. No real GTM or Google Analytics ID is
included.

## AI Assistance

AI tools were used to assist with initial code structure,
CSS refinement, JavaScript interaction implementation,
debugging, responsive review, and code review.
All implementation was reviewed, tested, and adjusted manually.

## GitHub Pages

This is a static website. It uses relative asset paths and does not require
Node.js, npm, a backend, or a database to run on GitHub Pages.
